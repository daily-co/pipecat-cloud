- Where your organization has suite runs, `eval run` runs a file's scenarios as one suite run, with one verdict, and shows their counts as they move. `--repeat N` runs each scenario N times (above 1 it's a measurement: pass rates and no verdict, exit 0 once it completes), `--concurrency N` caps how many run at once, and `--deadline` covers the whole suite run. A suite run that's cancelled, expires or ends in error exits 2. Without suite runs, or with `--param`, the scenarios run side by side as before. `eval suite run AGENT --bundle NAME[@N] --suite PATH` runs a suite file from a stored bundle (or `--revision ID`), `eval suite status`, `eval suite list` and `eval suite cancel` follow and stop suite runs, and `eval list AGENT --suite ID` lists a suite run's member runs. A suite run whose results were judged by more than one judging version says so, and a measurement's pass rates are split by version.
