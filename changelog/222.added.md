- `pipecat cloud eval` runs scenarios against a deployed agent and reads the results. `eval run AGENT SCENARIO_FILE` runs a file's scenarios (every one, or those named with `--scenario`) and waits for them as `pipecat eval run` does; `eval judge AGENT SESSION_ID... --criteria FILE` judges finished sessions without a simulated caller; `eval status`, `eval list` and `eval cancel` follow and stop runs. Waiting commands exit 0 for `passed` or `skipped`, 1 for `failed`, 2 for a run that ended without a verdict and 3 for an API or usage error; Ctrl-C stops waiting, leaves the runs going and exits 130. The scenario file and the files it `!include`s are sent from `--root` as UTF-8 text, up to 256 KiB, and hidden files, files that look like they hold secrets, symlinks that leave the root and non-UTF-8 files are refused before anything is sent. `-v` explains every run with its conversation, and every command takes `--json`.
