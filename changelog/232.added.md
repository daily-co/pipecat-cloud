- `pcc-deploy.toml` accepts `whatsapp_auth` (`"none"` or `"token"`). With `"token"`, the agent's WhatsApp webhook requires your organization's public API key. The CLI warns when the API doesn't confirm the setting.
- Redeploying an agent that has `whatsapp_auth` or `websocket_auth` set to `"token"` from a `pcc-deploy.toml` without that key resets it to `"none"`, as before. The CLI now warns about this before you confirm the deploy.
